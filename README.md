# CodeAlpha Data Visualization Project

## Overview
This project is part of the CodeAlpha Data Analytics Internship. 
The objective is to visualize data using Python to uncover patterns and insights.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Visualizations Created
- Histogram (Math Score Distribution)
- Bar Chart (Gender Distribution)
- Box Plot (Performance Comparison)

## Conclusion
Data visualization helped transform raw data into meaningful insights, making patterns and comparisons easier to understand.
